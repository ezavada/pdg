Detailed Description

A configurable point source of independent particles.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

◆ setParticleTemplate()

ParticleEmitter setParticleTemplate ( Particle particle)

Capture the configuration for future emissions.

Copies settings and remaining scheduled actions immediately. Subsequent source-setting edits require another call. Shared artwork edits remain visible. Every emitted physical body is independent; constraints and external references are omitted. A relative angular-speed threshold is disabled in the captured template because its external reference is not copied.

Parameters
particleSource configuration; a fresh detached Particle is recommended.
Returns
This ParticleEmitter.

◆ setVelocityInheritance()

ParticleEmitter setVelocityInheritance ( number value)

Set initial velocity inheritance.

Default 0. Adds this multiple of emitter velocity to the directed emission velocity. Continuous emission samples motion during the tick, including scheduled motion and parent movement; explicit bursts use current configured movement/body velocity.

Parameters
valueFinite nonnegative multiplier; 1 inherits the entire velocity. JavaScript parameter is named value.
