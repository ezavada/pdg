Detailed Description

Animate a single bone in a Sprite's current rig.

Use Sprite::getBone() after enabling the animation pose. Bone inherits Animated scheduling, scripts, easing, waits, pause, cancellation and completion handlers. Position and attachment coordinates are parent-relative; rotation is in radians and time is in seconds. moveTo(), rotateTo() and changeScaleTo() override their channels, starting from the displayed value. moveBy() and rotateBy() add to each fresh clip sample. changeScaleBy() adds a scale delta to each fresh clip sample. Completed controls persist.

Height measures bone length and width measures its transverse bounds/capsule. Resize keeps child attachment positions proportional while preserving child sizes. Scale and flip propagate through descendants. Imported bone axes are preserved. Initial dimensions come from child connection distances, with unit length for a terminal bone; physical bones use their capsule dimensions. centerOffset is the attachment point in the parent frame; changing it adds a displacement from its reference position to the running clip's attachment motion.

Controls run before pose modifiers and IK. Final rotations honor explicit limits, limits on a corresponding named Part, configured two-bone IK limits, and rotary limits connecting mapped physical Parts. Physical simulation owns dynamic poses; scripted controls supply animation targets. Resize updates capsule geometry and joint anchors outside locked solver callbacks. Scaling or reflecting a single live physical bone requires disabling animation physics first; use resize for physical dimensions, or Sprite flip to reflect the entire physical assembly.

The Sprite advances controls automatically, including while its clip is paused. Use pauseSchedule() to pause the controls. Pose queries never advance their clocks. Replacing or disabling the rig invalidates handles. isAttached() remains safe; other getters and edits throw after invalidation. Bone handles and their controls are runtime state and are not included in Sprite snapshots.

Note
The Sprite must have an enabled animation pose. Do not edit controls inside pose modifier callbacks. Use the callback's borrowed pose to edit that pose.
Example
const forearm = sprite.getBone('forearm');
forearm.series()
.rotateBy(0.5, 0.3, pdg.easeInOutQuad)
.wait(0.2)
.diminish(0, 0.25)
.endSeries();

Bone diminish ( number influence,
number seconds,
int easing = linearTween )

Ease scripted bone influence back toward the running animation.

Note
Parameter easing: EasingFunction.

Blends controlled channels toward each fresh authored sample. Zero releases all controlled channels, including flips. This changes scripted influence, not alpha. A value between zero and one retains the corresponding fraction of control.

◆ setIKLimits() [2/2]

Bone setIKLimits ( PhysicsConstraint constraint)

Share a live rotary limit with the bone.

The constraint must join this bone's physical Part and its physical parent. Changes to the constraint update limits immediately. Disconnecting it releases its limit; clearIKLimits() removes the explicit association without disconnecting physics. Automatically discovered physical or IK limits may still apply.

Parameters
constraintActive rotary limit for this bone's physical joint.
Returns
This Bone for chaining; incompatible constraints throw.
