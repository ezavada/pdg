Detailed Description

Spring target smoothing and recoil impulses.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

Keeps position and velocity independently of a Sprite. Call update() with a target and elapsed seconds to smooth motion, or applyImpulse() to produce recoil. getState() returns a copy; setState() replaces all position and velocity fields.

The helper does not update automatically. Apply each sample to a freshly evaluated pose instead of adding it repeatedly to the previous final pose.

AnimationSpringTarget ( number mass = 1,
number stiffness = 100,
number damping = 20 )

Create a damped spring target.

Starts with zero position and velocity. The helper owns its state independently of Sprites and does not update automatically. All inputs must be finite.

Parameters
massPositive mass; default 1.
stiffnessNonnegative restoring spring coefficient; default 100.
dampingNonnegative damping coefficient; default 20.
Example
const recoil = new pdg.AnimationSpringTarget(1, 100, 20);
recoil.applyImpulse(-2, 0);
const offset = recoil.update(0, 0, 1 / 60);
// Apply offset.x/y to a freshly sampled pose.
