◆ clipOverflow()

Attributes clipOverflow ( boolean clip)

Confine drawing overflow to the operation's bounds.

Defaults to false. When true, the operation temporarily intersects the current Port clip with its transformed axis-aligned bounds, restoring the Port clip on return. False allows operation overflow but never disables the Port clip.

Bounds are the supplied rectangle, quad or polygon bounds for closed shapes; the ellipse or sphere bounding rectangle; measured text bounds for point text; the supplied rectangle for rectangle text; and Drawing geometry bounds mapped into the requested destination for Drawing replay. Line and spline bounds include half the stroke width in Port pixels, so horizontal and vertical paths remain visible; arc bounds use their ellipse with the same stroke allowance. Other closed-shape bounds exclude the outer half of their stroke. Bounds follow translation, rotation, scaling and reflection as an axis-aligned enclosing rectangle.

Images and image strips also crop fitted artwork to the destination before its transform, including rotated destinations, subsection/frame selection and all fit modes. fit_Clipped always crops; tiling crops partial edge tiles. Nested Drawing replay respects its enclosing operation clip without exposing a public clip stack.

Parameters
clipTrue to clip overflow; false to allow it within the Port clip.
Returns
This Attributes object, for chaining.
See also
Port::setClipRect(), Port::resetClipRect()

◆ lightOffset()

Attributes lightOffset ( Offset offset)

Sets light source with spherical coordinates in radians.

The lightOffset is an Offset with two values representing spherical coordinates in radians: offset.x (ρ/rho): Horizontal angle (azimuth) - rotation around the vertical axis offset.y (θ/theta): Vertical angle (elevation/polar angle) - angle from the horizontal plane

Key Points Offset(0, 0): Light directly in front at horizon level Offset(π/2, 0): Light from the right side at horizon level Offset(0, π/2): Light from directly above Offset(π, 0): Light from behind at horizon level The values are relative to the sphere's center, with the light positioned at a distance proportional to the sphere's radius.

◆ setTransform()

Attributes setTransform ( array number matrix)

Replace the affine transform immediately.

Unlike transform(), replaces the matrix instead of postmultiplying it. AnimatedAttributes preserves its logical width and height, adopts the matrix as its shared Animated state, and cancels conflicting transform animation. It rejects nonfinite or non-affine matrices and nonzero matrix columns whose corresponding logical dimension is zero.

Parameters
matrixArray of nine numbers in column-major order. For a 2D affine transform use [a, b, 0, c, d, 0, tx, ty, 1], mapping (x,y) to (a*x+c*y+tx, b*x+d*y+ty).
Returns
This object, for chaining.
Example
style.setTransform([1, 0, 0, 0, 1, 0, 20, 10, 1]);
See also
transform(), getTransform()

◆ withAppearance()

Attributes withAppearance ( Attributes overrides,
boolean textOnly = false )

Copy this drawing style with explicitly assigned appearance overrides.

Parameters
overridesAn Attributes or AnimatedAttributes sample. Only channels explicitly set or scheduled on that source override this base. Setting a default value is explicit; for example, roundedCorners(0) removes a base style's rounded corners.
textOnlyDefaults to false. True applies only text size, text style, font, fill opacity and blend mode, preserving the base foreground and other styling.
Returns
An independent Attributes snapshot. Neither source changes, and this base's transform is preserved. Transform, location and size from overrides are not copied.

Appearance animation owns its channel when scheduled and contributes its current value; this method does not advance either source. MVC uses this to compose View appearance with the selected ControlAttributes state. Custom draw routines can use the same method.

Note
API stability: 2 — Evolving.
