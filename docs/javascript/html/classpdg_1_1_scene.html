Detailed Description

Own layers, an isolated physics world, a camera, timers and simulation time.

Create gameplay first and HUD second: scenes draw in construction order above legacy layers. Both can target the same Port. Pausing gameplay keeps drawing its held pose while the HUD continues to animate and receive its own timer events. Raw input is controlled separately with setInputEnabled(boolean).

addLayer(layer) adopts a detached layer or a layer from the legacy factory. removeLayer(layer) detaches without destroying sprites or their physical state; the caller must attach it elsewhere or clean it up. disposeLayer(layer) destroys an attached layer. dispose() is idempotent, cancels timers and subscriptions, and destroys remaining attached layers. Detached layers survive. Cross-layer physics constraints must be disconnected before detachment. Mutation of layer membership must occur outside scene traversal. Deferred disposal is safe inside callbacks.

The effective layer camera is its explicit override, otherwise its Scene camera, otherwise its Port camera. Scene cameras and layer overrides advance once on the owning scene clock. A camera cannot be automatically advanced by two scenes.

advance(seconds), setFixedStep(seconds), getSimulationTime() and getDroppedTime() use seconds. setManual(true) disables automatic host advancement. Fixed step 0 selects variable stepping; a positive value selects fixed stepping. Updates admit at most 0.25 seconds of host time and run at most eight fixed steps. Excess whole steps are discarded and reported by getDroppedTime(); discarded time does not fire logical timers. setTimeScale(scale) accepts finite nonnegative values. Zero freezes advancement without setting isPaused(). Resume adds no paused-time debt.

setInterpolation(true) enables read-only interpolation of sprite root translation, scale and shortest-path rotation during fixed-step rendering. Mounted sprites inherit the parent correction. Queries and physics retain authoritative state; skeletal poses and camera poses use current state. A teleport resets presentation.

Scene timer delays and intervals use milliseconds. IDs are positive and local to each scene. onTimeout(callback, delayMs) and onInterval(callback, intervalMs) return cancellable handles. Callbacks receive the timer event synchronously. Repeating intervals must be positive; zero-delay one-shots wait for the next update. Timers fire before animation at an update boundary, at most once per step, and newly created timers wait for a later boundary. Scene pause includes timers created while paused. Scene resume preserves individually paused timers. Scaling affects logical deadlines; getWhenTimerFiresNext(id) returns the logical deadline in milliseconds, or -1 for an absent or paused timer.

subscribe(emitter, eventType, callback) returns a cancellable external registration and disconnects it on explicit dispose(). Pause does not suppress raw external events. Async work and sound servicing continue independently; applications decide when to apply late results and pause gameplay voices.

Note
Rendering requires a graphics-capable build. Manual simulation, timers and camera animation are available headlessly. Explicitly dispose scenes when leaving a level; garbage collection is not a lifecycle boundary.
const gameplay = new pdg.Scene();
gameplay.setFixedStep(1 / 60);
gameplay.setInterpolation(true);
const hud = new pdg.Scene();
const worldLayer = gameplay.createSpriteLayer();
const hudLayer = hud.createSpriteLayer();
worldLayer.setSpritePort(port);
hudLayer.setSpritePort(port);
hud.onInterval(function () { caret.setOpacity(caret.getOpacity() ? 0 : 1); }, 500);
gameplay.pause(); // HUD continues above the held gameplay image.
gameplay.resume();
// On leaving this level:
gameplay.dispose();
hud.dispose();

◆ raycast() [1/2]

CollisionQueryHit raycast ( Point start,
Point end,
CollisionQueryOptions options = undefined )

Return the closest accepted segment entry hit, or null. Queries inspect current authoritative scene geometry before stepping and while paused, independently of cameras, render interpolation, visibility, input and collision-response switches. Enabled attached Sprite, Part and Particle colliders are eligible, including bodyless colliders. Basic and Chipmunk configurations use the same geometry algorithms. Touching counts and a zero-length ray tests containment.

Call outside scene update/draw traversal. Queries during advance(), including timer and contact callbacks, and recursive queries from predicates throw. Predicates must not mutate geometry, scene membership or results, advance scenes, or dispose scenes or layers. Predicate errors propagate and leave the reused array empty.

The scene reuses one array and a pool of hit records, including their Point and Vector fields. All returned arrays and hits are valid until the next query on that scene or disposal. This includes single-hit queries. Copy fields and coordinates when keeping a result; copying the array alone does not copy its hit records. Queries on another scene do not invalidate these results. Treat returned arrays, records and coordinates as read-only. Disposal empties the array and clears its collider references. Hit records retain colliders while active; shape IDs may cease to exist after geometry changes.

Shared query options
Field Default Meaning
maxHits 16 Overlap limit, integer 0 to 1048576; zero returns an empty array. Cast array overloads take maxHits as a separate parameter.
layerMask 4294967295 Unsigned 32-bit mask intersecting layer queryBits. Zero selects none. Layers default to bit 1.
layers All scene layers Optional SpriteLayer array intersected with layerMask. Empty selects none; foreign/detached layers throw.
categoryMask 4294967295 Unsigned 32-bit mask intersecting collider categories.
includeSensors true Include sensor colliders.
excludedColliders Empty Collider identities to exclude.
excludedBodies Empty PhysicsBody identities whose colliders are excluded.
predicate None Synchronous boolean function(collider), called once per eligible collider before limiting results.

CollisionQueryHit fields
Field Meaning
collider, shapeId Collider and public shape identity.
point Cast target point or nearest point on filled geometry. Initial overlaps can return an interior point.
normal Outward normal toward the query; zero for initial overlaps and nearest points inside a shape.
fraction Cast travel fraction in [0,1].
distance Cast travel distance or nearest filled-geometry distance in world units.
initialOverlap Cast starts touching/overlapping; distance and fraction are zero.

Overlap results expose identity only; other fields are zero. Array overloads of raycast(start, end, maxHits, options) and sweepCircle(center, radius, delta, maxHits, options), and overlap methods, return at most maxHits entries, sorted by distance, collider ID and shape ID. Overlaps use identity ordering. Decomposition pieces do not duplicate a public shape hit. Arrays have exactly the stored hit count; a miss returns an empty array. No truncation flag is exposed. Circle sweeps translate against current stationary geometry; nonuniform scale/shear uses the existing curved-boundary approximation. Layer queryBits are runtime settings and are not serialized in layer snapshots. Finite coordinates and nonnegative finite radii/distances are required. Boxes must have positive dimensions. Invalid requests throw.

Storage is reused after warming up to the requested capacity. Geometry snapshots, candidate collection, script/native argument transport and sorting may still allocate; the API does not promise allocation-free queries.

Parameters
startScene world-space segment start.
endScene world-space segment end.
optionsOptional selection; see scene_collision_query_options.
Returns
Closest accepted CollisionQueryHit, or null. The hit is reused on the next query.
Note
Attach searched layers to a live scene; no physics step is required.
Example
const game = new pdg.Scene();
const terrain = game.createSpriteLayer();
terrain.createSprite().setupCollider().setBox(new pdg.Rect(100, 0, 120, 100));
const hit = game.raycast(new pdg.Point(0, 50), new pdg.Point(200, 50));
if (hit) console.log(hit.distance); // 100 world units
const hits = game.overlapCircle(new pdg.Point(110, 50), 20, {maxHits: 8});
for (const entry of hits) console.log(entry.shapeId);
// Keep a copy before another query reuses entry and its coordinate objects.
const saved = hits.map(entry => ({collider: entry.collider, shapeId: entry.shapeId}));
game.dispose();
