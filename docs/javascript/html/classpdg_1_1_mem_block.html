Detailed Description

Hold native memory for exchange between PDG APIs.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

A MemBlock is either an owned block or a borrowed view of another native object's storage. Serializer.getDataPtr() returns a borrowed block: keep the serializer alive and do not modify or clear it while using that block.

getData() and getBytes() return independent Uint8Array copies. Use those snapshots when the data must outlive its native owner. See getData() for Node.js Buffer conversion and the copy cost of each conversion form.

Uint8Array getData ( )

Copy the block's bytes into a new plain Uint8Array.

Returns the same standard JavaScript array type on desktop native, Node, browser, and iOS runtimes. Each call copies all bytes without text decoding, including zero and values above 127. Changing the returned array does not change this MemBlock or arrays returned by earlier calls.

Returns
An independently owned Uint8Array with getDataSize() elements, or an empty Uint8Array for an empty block. The result is not a Node Buffer; slice() copies bytes and subarray() shares the returned array's memory.
Example
const writer = new pdg.Serializer();
writer.serialize_1u(255);
const bytes = writer.getDataPtr().getData();
const copy = bytes.slice();
Node.js Buffer conversion
Use this form when a Node.js API specifically requires a Buffer. getData() copies the native block once; the Buffer then shares that snapshot without another payload copy. Include the offset and length so only the array's visible bytes are exposed, even when converting a subarray.
Note
These examples require Node.js Buffer support. The shared Buffer and Uint8Array reflect each other's mutations, but neither changes the MemBlock.
const bytes = writer.getDataPtr().getData();
const buffer = Buffer.from(bytes.buffer, bytes.byteOffset, bytes.byteLength);
Warning
The shorter form below makes an additional full copy of the bytes: one copy from native memory into the Uint8Array, then another into the Buffer. For an N-byte block, it copies 2N bytes and needs storage for both N-byte payloads until the temporary array can be collected. This adds copy time and memory/garbage-collection pressure, especially for large or frequent transfers. Use it when an independent Buffer copy is intentional.
const bufferCopy = Buffer.from(writer.getDataPtr().getData());

The removed MemBlock.toBuffer() method can be replaced by the shared-view form above with the same single payload copy.
