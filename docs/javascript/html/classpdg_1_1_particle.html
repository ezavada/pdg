◆ setTrail()

Particle setTrail ( ParticleTrailOptions options)

Configure a bounded ribbon following the particle's motion.

Parameters
optionsTrail settings; omitted fields use ParticleTrailOptions defaults.
Returns
The receiver for call chaining.

The ribbon records positions in layer coordinates after particle motion and physics. Camera motion does not add history. Width and minimum distance are layer units; lifetime and sampleInterval are simulation seconds. Width and opacity interpolate linearly toward endWidth and endOpacity as each sample ages. Color alpha multiplies the sampled particle opacity. A temporary head joins the latest stored point to the current position. maxPoints bounds stored history; reaching that limit shortens the visible trail. Rendering uses solid, antialiased CPU ribbons with normal alpha blending.

Calling setTrail again replaces the configuration and clears history. Particle emitter templates copy settings with empty history. Expiring particles release their physics and particle budget slot immediately; the layer retains only their fading ribbon. Retired ribbons are limited to the layer's particle budget and 65536 reserved history points, evicting oldest tails first when necessary. Removing a particle explicitly clears its history; removeAllParticles and layer disposal also clear retired tails. Trail configuration and recorded script arguments are portable; live trail histories are transient and omitted from layer snapshots.

Layer animation pauses and scene simulation clocks also govern trail aging. Explicit setLocation calls reset history. breakDistance resets it when one simulation step moves farther than its limit; use 0 to disable this safeguard. Use breakTrail for other discontinuities. No ribbon is drawn until it has two distinct points.

Note
GUI targets render trails. Headless targets still simulate and validate them. No Image, Drawing, collider or physics body is required. This call is also available on AnimationScript and Troupe recorders for Particle playback targets.
const prototype = new pdg.Particle().setLifetime(1.5)
.setTrail({lifetime:0.4, width:6, endWidth:0, color:'orange',
minDistance:2, maxPoints:32});
layer.createParticleEmitter().setParticleTemplate(prototype)
.setLocation(200,300).setRotation(-Math.PI/2)
.setParticleSpeed(150,200).setSpread(0.5)
.setEmissionRate(25).startEmitting();
