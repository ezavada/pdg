◆ pdg::PortDrawEvent

struct pdg::PortDrawEvent

PortDrawEvent.

a port needs to be redrawn (GUI Only)

Note
Documentation-only JavaScript shape, not a runtime constructor.
Fields
Field Type Required/default Meaning
emitter EventEmitter Required
eventType number Required
frameNum number Required
port Port Required

Generated by the GraphicsManager whenever it is time to redraw a Port. All drawing calls should be done during the handling of a pdg.eventType_PortDraw. 

{ 
    emitter: {},       // the emitter that generated this event
    eventType: 24,     // the event type (eventType_PortDraw)
    port: {},          // the port that needs to be redrawn
    frameNum: 12897    // how many times this event has been generated for this port
}
Note
these events are never generated in a non-GUI build, such as the PDG Node.js plugin
See also

◆ pdg::PortResizedEvent

struct pdg::PortResizedEvent

a port has been resized (GUI Only)

Generated by the GraphicsManager whenever a Port is resized or when the device orientation is changed. 

{ 
    emitter: {},       // the emitter that generated this event
    eventType: 15,     // the event type (eventType_PortResized)
    port: {},          // the port that was resized
    screenPos: 0       // one of the screenPos_ constants, in this case screenPos_Normal
}
Note
these events are never generated in a non-GUI build, such as the PDG Node.js plugin

const CopyPixels = true

Copy an offscreen surface's current pixels into an independent Image. Read-only boolean constant equal to true. The default for Image::Image(Port, boolean). Available in every JavaScript runtime; constructing images from a Port requires graphics support.

◆ SharedSurface

const SharedSurface = false

Share an offscreen surface so later Port drawing updates the Image. Read-only boolean constant equal to false. Use new pdg.Image(port, pdg.SharedSurface). The Image retains the surface after the source Port closes. Available in every JavaScript runtime; constructing images from a Port requires graphics support.
