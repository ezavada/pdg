Detailed Description

Interface for an object which can be serialized.

Note
API Stability: 3 — Stable. This public contract is established. Compatible changes are expected; intentional breaking changes require an announced breaking release and migration guidance. See API stability.

API stability does not promise a fixed snapshot byte format; see API stability.

Declare a JavaScript class extending pdg.ISerializable and implement these four methods:

  • getSerializedSize(serializer) returns the byte count for the object's data. Use the serializer's sizeof_*() methods to match its encoding.
  • serialize(serializer) writes the object's fields using serialize_*().
  • deserialize(deserializer) reads them using deserialize_*(), in the same order and with the same types used when writing.
  • getMyClassTag() returns a stable, unique unsigned 32-bit tag identifying the class. Zero is invalid; 0xFFFFFF00 through 0xFFFFFFFF are reserved by PDG.

The native constructor takes four callbacks in that order. Pass forwarding functions to super() so native serialization calls your class methods with the correct receiver. Initialize instance fields after super() returns.

Register the class with pdg.registerSerializableClass() before deserializing its objects. The registered constructor must support being called without arguments, so provide defaults for any constructor parameters.

Example

class MySerializableClass extends pdg.ISerializable {
constructor(one = 15, two = 99) {
super(
function(serializer) { return this.getSerializedSize(serializer); },
function(serializer) { this.serialize(serializer); },
function(deserializer) { this.deserialize(deserializer); },
function() { return this.getMyClassTag(); }
);
this.one = one;
this.two = two;
}
getSerializedSize(serializer) {
return serializer.sizeof_1u(this.one) + serializer.sizeof_2u(this.two);
}
serialize(serializer) {
serializer.serialize_1u(this.one);
serializer.serialize_2u(this.two);
}
deserialize(deserializer) {
this.one = deserializer.deserialize_1u();
this.two = deserializer.deserialize_2u();
}
getMyClassTag() {
return 0x4068; // reserve a unique tag for this class in your application
}
}
pdg.registerSerializableClass(MySerializableClass);
const original = new MySerializableClass();
const serializer = new pdg.Serializer();
serializer.serialize_obj(original);
serializer.serialize_obj(original); // writes a reference to the same object
const deserializer = new pdg.Deserializer();
deserializer.setDataPtr(serializer.getDataPtr());
const first = deserializer.deserialize_obj();
const second = deserializer.deserialize_obj();
console.assert(first instanceof MySerializableClass);
console.assert(first.one === 15 && first.two === 99);
console.assert(second === first); // shared references preserve object identity

Objects can serialize other objects with serialize_obj(). The serializer tracks objects within the stream, so repeated references and parent/child cycles do not require duplicate object data. Use sizeof_obj() when calculating space for nested serialized objects.
