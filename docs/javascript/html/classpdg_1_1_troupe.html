Detailed Description

Animate a collection of targets with one script clock.

Troupe inherits Animated's controls and exposes the same semantic subclass commands as AnimationScript. add(), remove() and clear() edit direct membership. Sprites, Parts, AnimatedAttributes, ordinary Animated targets and other Troupes are accepted. Members are borrowed; keep their native objects or JavaScript wrappers alive while using them. Expired targets are skipped. Self-membership and cycles throw. A repeated direct add is idempotent. Nested membership is flattened in insertion order and a leaf target receives each operation once, even when multiple membership paths reach it.

Commands use each member's own coordinate system and activation-time baseline. A batch or series has collective completion dependencies, and a conditional or until evaluator for the shared graph sees the Troupe. Staggering an entire block creates separate member executions; evaluators inside that staggered block see the member target. Targets and order are captured when the block is published. Removing a member stops its outstanding contribution on the next Troupe update; additions participate in subsequently published blocks.

Advance the Troupe with animate(deltaSeconds) once per frame, before its members' ordinary animation updates when using programmed-rate profiles. The Troupe drives only its shared script; it does not call Sprite physics, drawing, managers or nested Troupes' independently scheduled work. Members retain their normal update owners. Member setters interrupt matching Troupe channels. Programmed-rate contributions are integrated by the Troupe and consumed once by the member's next ordinary update. Troupe snapshots serialize direct members, including nested Troupes, through object references and preserve collective playback and saved marks. A restored Troupe retains its loaded members. Part members reference the owning Sprite and stable Part ID, so a separately saved Sprite or layer shares the same restored Part. Detached Parts have no standalone snapshot format and raise an error. Write layers, Troupes and independently saved members through the same Serializer to share identities without duplication. Full layer records use object references for Sprites. Layers do not automatically include Troupes; the application must explicitly save each Troupe whose collective animation should resume. Saving a member alone preserves its own animations, while collective playback is stored in the Troupe.

Example
const dancers = new pdg.Troupe().add(alice).add(bob);
dancers.moveBy(50, 0, 1).stagger(0.1).andThen().rotateBy(1, 0.5);
