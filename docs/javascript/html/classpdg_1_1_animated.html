Detailed Description

something that can be automatically moved, spun or resized over time.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

Animated separates immediate edits and constant rates from scheduled transitions. All animation durations and waits use floating-point seconds. Setters are immediate and chainable; they cannot consume a wait() or andThen(). Timed change methods require explicit seconds; explicit zero applies immediately outside a sequence. To names specify targets; By names specify additive deltas. grow() and stretch() use factors and change logical size; changeScaleTo()/changeScaleBy() change the independent transform scale. Constant rates continue after a rate transition ends.

Scheduled operations normally run concurrently. andThen() sequences the next operation after the most recently scheduled one; wait() delays the next timed request. Immediate calls after either throw before changing state. cancelSchedule() clears pending sequencing and scheduled work while retaining current constant rates.

Example
sprite.setMovement(40, 0);
sprite.changeMovementTo(0, 0, 0.5); // Ease the rate to a stop in half a second.
sprite.setGrowing(8); // Add eight logical size units per second.
sprite.changeGrowingTo(0, 0.25); // Ease the growth rate to zero.

PhysicsBody owns physical velocity, mass, damping, forces and impulses.

It has no drawing capabilities, so it is not intended to be used directly in most cases, but rather as a base class for items that can be animated. It could be used on a server to drive animation that is rendered on the client.

◆ addAnimationHelper()

Animated addAnimationHelper ( IAnimationHelper helper)

Register a callback after the object's normal animation step.

The callback runs as callback.call(helper, owner, deltaSeconds) and returns a boolean: true keeps its registration, false retires it. Helpers run in registration order. Adding the same helper twice to one owner has no effect; a helper may also be registered on several owners. A retained helper can be added again after it finishes.

Callbacks may remove themselves, remove another helper, or clear the owner's helpers. Removed callbacks do not run later in the same step. Additions first run on the next step. Removing and re-adding the current helper creates a new registration, which is unaffected by the old callback returning false.

Parameters
helperAn IAnimationHelper constructed from a callback. Active registrations retain it. After retirement, normal JavaScript references determine its lifetime.
Returns
The original owner object, for chaining.
Example
const helper = new pdg.IAnimationHelper(function(owner, deltaSeconds) {
owner.rotateBy(deltaSeconds * 0.5);
return true;
});
sprite.addAnimationHelper(helper).setMovement(20, 0);
// Later: sprite.removeAnimationHelper(helper);

Animated andAlso ( )

Join the following operand to the preceding parallel chain.

Returns
This object for chaining. Requires a preceding operand that has not activated and a following operand. Repeated calls extend an implied batch. Following until(), yoyo(), repeat(), timing, amplitude and playback controls select that complete chain. Inside a series, the chain is one step and the next ordinary operand waits for every member to complete. Pending explicit andThen() placement is incompatible with andAlso().

.endSeries();

◆ andThen()

Animated andThen ( )

Start the next timed operation after the most recently scheduled operation finishes.

Uses the selected operation or block, rather than all concurrent work. Script dependencies observe actual completion, including repeat, timing modifiers, and until(). The next request consumes this sequencing state; later calls again run concurrently unless sequenced. A successor acquires its properties and resolves relative targets when it starts. Inside script construction, immediate commands are recorded and run at activation; ordinary immediate calls outside construction retain their existing restrictions. andThen().wait(seconds) composes completion with a delay. No then() method is provided, so returning an Animated object from an async JavaScript function is safe.

Returns
This object, for chaining.
See also

◆ on()

Animated on ( string event,
function handler )

Observe a selected animation block's lifecycle.

Note
Parameter handler: AnimationEventHandler.
Parameters
eventA custom nonempty event name, or started, finished, scriptFinished, mark, yoyo, repeat or untilFired.
handlerFunction receiving a plain AnimationEvent record. Its return value is ignored.
Returns
This object for chaining.

On Sprite, numeric on(eventCode, handler) keeps its existing EventSubscription return; string lifecycle events return the Sprite for chaining.

Registration applies to the selected operand, or to the current empty recorder/block before its first operand. Multiple handlers run in registration order. Register after a modifier to observe that modifier. Named definitions retain their handlers; each invocation has its own playback state. Registration does not emit events retroactively.

started and finished describe only the selected block. Other events propagate from children to enclosing blocks. finished means successful natural completion or completion through until(); stopIt() and channel cancellation do not report success. scriptFinished identifies completed named invocations, including nested invocations. yoyo fires at the forward-to-reverse turn; repeat fires before each additional iteration, starting at iteration 1. untilFired fires only when the condition ends the operand early; natural completion does not emit it. mark fires whenever a mark is reached, including repeat visits.

Handlers run synchronously after each scheduler substep publishes state, in traversal order. A handler may change the target or start another animation. The target reflects published state at delivery, which can be later than the individual event boundary when a substep crosses several events. Handler exceptions propagate to the caller; already delivered events are not replayed. Context and target are borrowed for the callback; copy the scalar fields if they are needed later. Handlers are runtime resources and reject portable snapshots.

For Troupes, finished on the collective block fires once after all members complete. Events inside staggered member scripts identify that member as target.

Example
const actor = new pdg.Animated();
actor.moveBy(100, 0, 2).andAlso().rotateBy(1, 2)
.until(context => context.target.getLocation().x >= 50)
.on("untilFired", event => event.target.moveBy(0, -20, 0.5));
actor.animate(1);
actor.animate(0.5); // interruption handler starts the upward move

scriptNameNearest enclosing named script; empty for anonymous animation.
markNameMark label for a mark event; otherwise empty.
elapsedSecondsElapsed local time of the emitting operand.
iterationAdditional repeat iteration, starting at 1 for repeat events; otherwise 0.
