Detailed Description

something that can be automatically moved, spun or resized over time.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

Animated separates immediate edits and constant rates from scheduled transitions. All animation durations and waits use floating-point seconds. Setters are immediate and chainable; they cannot consume a wait() or andThen(). Timed change methods require explicit seconds; explicit zero applies immediately outside a sequence. To names specify targets; By names specify additive deltas. grow() and stretch() use factors and change logical size; changeScaleTo()/changeScaleBy() change the independent transform scale. Constant rates continue after a rate transition ends.

Scheduled operations normally run concurrently. andThen() sequences the next operation after the most recently scheduled one; wait() delays the next timed request. Immediate calls after either throw before changing state. cancelSchedule() clears pending sequencing and scheduled work while retaining current constant rates.

Example
sprite.setMovement(40, 0);
sprite.changeMovementTo(0, 0, 0.5); // Ease the rate to a stop in half a second.
sprite.setGrowing(8); // Add eight logical size units per second.
sprite.changeGrowingTo(0, 0.25); // Ease the growth rate to zero.

PhysicsBody owns physical velocity, mass, damping, forces and impulses.

It has no drawing capabilities, so it is not intended to be used directly in most cases, but rather as a base class for items that can be animated. It could be used on a server to drive animation that is rendered on the client.

◆ addAnimationHelper()

Animated addAnimationHelper ( IAnimationHelper helper)

Register a callback after the object's normal animation step.

The callback runs as callback.call(helper, owner, deltaSeconds) and returns a boolean: true keeps its registration, false retires it. Helpers run in registration order. Adding the same helper twice to one owner has no effect; a helper may also be registered on several owners. A retained helper can be added again after it finishes.

Callbacks may remove themselves, remove another helper, or clear the owner's helpers. Removed callbacks do not run later in the same step. Additions first run on the next step. Removing and re-adding the current helper creates a new registration, which is unaffected by the old callback returning false.

Parameters
helperAn IAnimationHelper constructed from a callback. Active registrations retain it. After retirement, normal JavaScript references determine its lifetime.
Returns
The original owner object, for chaining.
Example
const helper = new pdg.IAnimationHelper(function(owner, deltaSeconds) {
owner.rotateBy(deltaSeconds * 0.5);
return true;
});
sprite.addAnimationHelper(helper).setMovement(20, 0);
// Later: sprite.removeAnimationHelper(helper);

removeAnimationHelper(), clearAnimationHelpers(), IAnimationHelper

◆ andThen()

Animated andThen ( )

Start the next timed operation after the most recently scheduled operation finishes.

Uses its remaining duration and delay, not the longest of all concurrent operations. The next request consumes this sequencing state; later calls again run concurrently unless sequenced. A successor acquires its properties and resolves relative targets when it starts. Immediate calls after andThen() throw even if the predecessor has finished. No then() method is provided, so returning an Animated object from an async JavaScript function is safe.

Returns
This object, for chaining.
See also
wait(), cancelSchedule()

Animate independent scale by additive deltas.

Does not change logical size. Adds to the scale components: starting at 2, adding 0.5 yields 2.5. Attributes::scale(0.5) instead multiplies and yields 1. With andThen(), deltas are applied to scale at the start of the operation. Negative scale reflects; zero collapses an axis and makes inverse transforms singular. Durations are explicit floating-point seconds. Zero applies immediately; a request after wait() or andThen() must have positive duration.
