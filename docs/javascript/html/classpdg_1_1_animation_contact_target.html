Detailed Description

World and platform contact locks with timed release.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

Preserves a contact point in owning-layer coordinates. lockWorld() holds a fixed point; lockPlatform() follows a support identified by the application. update() checks the supplied contact/reach policy and advances release fades in seconds.

The helper starts unlocked and never reacquires automatically. Call a lock method on a confirmed contact edge. getState() returns an independent copy of the point, influence, and lock flag.

◆ AnimationContactTarget()

AnimationContactTarget ( )

Create an unlocked contact target.

Starts at (0, 0), with influence 0 and locked false. The application chooses when contact starts and whether it remains reachable.

Example
const contact = new pdg.AnimationContactTarget();
contact.lockWorld(20, 10);
const state = contact.update(1 / 60, true, true);
console.log(state.x, state.y, state.influence);

lockPlatform ( number x,
number y,
number support,
object frame )

Lock a contact to a moving support.

Converts the world point into the platform frame. Subsequent update() calls transform that local point using the same support's current frame. Replaces any previous lock and resets influence to 1. Singular frames throw.

Parameters
xFinite contact x in owning-layer coordinates.
yFinite contact y in owning-layer coordinates.
supportStable nonzero integer support ID, at most Number.MAX_SAFE_INTEGER. It is an application identity, not a retained body pointer.
frameAn object containing finite x, y, rotation (radians), scaleX, scaleY, and alpha (0 to 1) values. It maps the platform into the owning layer; both scales must be nonzero.
Returns
No value.
Example
const frame = { x: 10, y: 0, rotation: 0, scaleX: 1, scaleY: 1, alpha: 1 };
contact.lockPlatform(12, 0, 1, frame);
frame.x = 11;
const state = contact.update(1 / 60, true, true, 1, frame);
// state.x is now 13.

◆ release()

release ( number fadeSeconds = 0)

Release the lock with an optional fade.

Sets locked false immediately and preserves the last position. Influence falls linearly to zero as update() advances time. An already released target is unchanged; release does not restart its fade.

Parameters
fadeSecondsFinite nonnegative fade duration in seconds; zero clears influence immediately.
Returns
No value.

object update ( number deltaSeconds,
boolean contactActive,
boolean withinReach,
number support = 0,
object frame = undefined,
number releaseSeconds = 0 )

Follow a support or advance the release fade.

Inactive contact, an unreachable target, or a missing/replaced platform ID releases the lock. World locks do not require a support. Released targets never reacquire automatically; call a lock method on the next contact edge. A zero time step preserves fade progress but can still update a platform point or release a lock.

Parameters
deltaSecondsFinite nonnegative elapsed time in seconds.
contactActiveWhether the application's contact window remains active.
withinReachWhether the application considers this contact reachable.
supportCurrent support ID, or 0 when absent. Must be a nonnegative safe integer.
frameCurrent full platform transform; required only while a platform lock remains active. Both scales must be nonzero.
releaseSecondsFinite nonnegative fade duration used if this update releases the lock.
Returns
An owned contact state; see animation_contact_state.
