Detailed Description

Bone bodies, joints, simulation state, and recovery to authored animation.

pdg::AnimationPhysicsDefinition contains pdg::AnimationPhysicsBody and pdg::AnimationPhysicsJoint entries. pdg::AnimationPhysicsBodyMode selects dynamic or kinematic bodies; pdg::AnimationPhysicsRootMode selects fixed or following roots. pdg::PhysicsBodyState reports positions and velocities through each mapped Part's physics property.

Use the Sprite physics methods for integration with its layer. The native pdg::AnimationPhysicsRig provides direct integration with a Chipmunk space when PDG_USE_CHIPMUNK_PHYSICS is enabled. Recovery durations are seconds, angular values are radians, and velocities are per second.

Animation physics requires Chipmunk. Basic is intentionally not an animation-rig backend.

AnimationPhysicsDefinition decodeAnimationPhysicsDefinition ( const std::vector< double > & values)

Decode a binding-layer physical definition.

Native applications should normally construct AnimationPhysicsDefinition directly. Rejects missing/trailing values and invalid numeric fields. Physical topology and dimension validation occurs when constructing the rig.

Parameters
valuesPacked header [version, rootMode, rootBody, selfCollisions, bodyCount], followed by body records, jointCount, and joint records. Body records contain bone, mode, mass, length, radius, offsetX, offsetY, offsetRotation, friction, elasticity, categories, mask. Joint records contain parent, child, parentX, parentY, childX, childY, minAngle, maxAngle, maxForce, collide. Boolean fields use 0 or 1.
Returns
Decoded AnimationPhysicsDefinition.
