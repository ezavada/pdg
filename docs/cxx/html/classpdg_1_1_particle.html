Detailed Description

Lightweight whole-body artwork, animation and optional physics.

Layer factories return borrowed references. Retain native references with addRef/release. Detached particles do not automatically advance. Lifetime and animation durations are simulation seconds; zero lifetime disables expiry. Expiry stops the owned emitter and removes the body from the physics world. No parts, subsections, skeletons or attachment points are exposed.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

◆ setTrail()

Particle & setTrail ( const ParticleTrailOptions & options)

Configure a ribbon and clear its previous history; no renderer is needed to sample it.

Configure a bounded ribbon following the particle's motion.

Parameters
optionsRibbon lifetime, sampling, width, color and fade settings.
Returns
The receiver for call chaining.

Positions are sampled after animation and physics in layer coordinates. Camera movement does not extend trails. Widths and minDistance are layer units; lifetime and sampleInterval are simulation seconds. Width and opacity interpolate linearly with sample age toward endWidth and endOpacity. Color alpha multiplies the sampled particle opacity. Fixed time samples are interpolated within a tick; minDistance filters nearby samples. maxPoints bounds stored history; a temporary render head connects it to the current position. Full history capacity shortens the visible trail.

Replacing settings, breakTrail(), and explicit setLocation() calls reset history. A per-step displacement above breakDistance resets it automatically; zero disables that safeguard. Emitter templates copy settings without history. At expiry, the layer retains only the fading ribbon while releasing the particle and physics. Removing a particle explicitly clears its history; removeAllParticles() and layer disposal also clear retired tails. Retired tails are capped by the layer particle budget and 65536 reserved history points; oldest tails are discarded first. Histories are transient and omitted from snapshots; configuration values in named scripts are serializable. Layer animation pauses and scene clocks govern aging.

Note
Headless builds sample trails; GUI builds render solid, antialiased CPU ribbons with normal alpha blending. No artwork or physics body is required. Nonfinite or out-of-range settings throw std::invalid_argument. sampleInterval must be at least 0.0001 seconds; maxPoints must be 2..4096, lifetime positive, dimensions and distances nonnegative, and color channels/endOpacity in [0,1].
