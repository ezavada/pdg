Detailed Description

Built-in interpolation curves and the easing callback signature.

pdg::EasingFunc describes a value over time; pdg::linearTween() and the ease-in, ease-out, and ease-in-out families supply built-in curves. Elapsed time and duration are floating-point seconds for both built-in and custom callbacks; see Animation timing.
