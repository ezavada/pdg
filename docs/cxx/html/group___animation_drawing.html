Detailed Description

Shared Drawing artwork attached to the evaluated pose and authored slots.

pdg::Sprite::addAnimationDrawable() accepts persistent pdg::Drawing artwork or a synchronous pdg::AnimationDrawings::Callback returning a shared Drawing handle. Returning an empty handle skips drawing for that invocation. Artwork shares editable Drawing contents, including edits through pdg::ElementRef.

pdg::AnimationDrawableOptions selects a bone, slot placement, order, stroke space, and optional bounds. Use pdg::AnimationDrawPlacement and pdg::AnimationStrokeSpace constants. pdg::AnimationDrawingContext provides the invocation's transform and an owned pose copy; the context expires when the callback returns.

pdg::AnimationDrawBounds describes bounds used for culling. Query pdg::Sprite::getAnimationDrawableError() for callback failures. Use pdg::AnimationDebugDraw flags with pdg::Sprite::setAnimationDebugDraw() to display bones, sockets, and collision boxes.
