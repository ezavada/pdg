◆ compose()

AnimationTransform compose ( const AnimationTransform & parent,
const AnimationTransform & local )
static

Compose a parent and local animation transform.

Uses Spriter component composition, including reversing the child angle under an odd-axis reflection. Does not introduce affine shear. Composition is not associative under nonuniform scale; evaluate the full ancestor chain for world transforms. Invalid inputs or overflow throw.

Parameters
parentValid parent transform.
localValid child transform in the parent frame.
Returns
The composed transform.

static

Blend two animation transforms.

Interpolates position, scale, and alpha linearly and rotation along the shortest angular path. Reflected scales may cross zero. Invalid inputs or influence throw.

Parameters

toEnd transform.
