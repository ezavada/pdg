Detailed Description

Shared animation state and polymorphic interface.

Use Animated<T> for fluent methods that return the concrete owner type.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

◆ addAnimationHelper()

AnimatedBase & addAnimationHelper ( IAnimationHelper * helper)
inline

Register a callback after the object's normal animation step.

Helpers run in registration order and receive elapsed floating-point seconds. Returning false retires that registration. Adding an already registered helper is an idempotent operation. A helper may be registered on several owners.

Removing or clearing helpers inside a callback skips their remaining calls on this step. Newly added registrations run on the next step. Removing and re-adding the current helper creates a new registration; returning false only retires the old one.

Parameters
helperNon-null callback object. If ownedByAnimated() returns true, each owner retains a native reference until registration ends and any executing callback returns. The final release deletes the helper. Keep your own addRef()/release() reference if you intend to reuse a helper after retirement. A borrowed helper (ownedByAnimated() returns false) must outlive its registrations and executing callbacks.
Returns
This object, for chaining.
See also
removeAnimationHelper(), clearAnimationHelpers(), IAnimationHelper

◆ andThen()

AnimatedBase & andThen ( )

Start the next timed operation after the most recently scheduled operation finishes.

Uses its remaining duration and delay, not the longest of all concurrent operations. The next request consumes this sequencing state; later calls again run concurrently unless sequenced. A successor acquires its properties and resolves relative targets when it starts. Immediate calls after andThen() throw even if the predecessor has finished. No then() method is provided, so returning an Animated object from an async JavaScript function is safe.

Returns
This object, for chaining.
See also
wait(), cancelSchedule()

◆ changeScaleBy()

AnimatedBase & changeScaleBy ( float deltaX,
float deltaY,
double durationSeconds,
EasingFunc easing = easeInOutQuad )

Animate independent scale by additive deltas.

Does not change logical size. Adds to the scale components: starting at 2, adding 0.5 yields 2.5. Attributes::scale(0.5) instead multiplies and yields 1. With andThen(), deltas are applied to scale at the start of the operation. Negative scale reflects; zero collapses an axis and makes inverse transforms singular. Durations are explicit floating-point seconds. Zero applies immediately; a request after wait() or andThen() must have positive duration.
