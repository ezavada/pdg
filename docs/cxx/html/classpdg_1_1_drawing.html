Add owned UTF-8 text laid out in a local rectangle using text attributes.

Add owned, editable UTF-8 text to drawing artwork.

Copies the text and attributes. Font, text size/style, fill color and fill opacity follow Port::drawText(). Newlines are supported. The rectangle supplies the local layout bounds and four corner control points; hit tests use its box. Element and parent transforms and opacities apply normally, including live attributes.

Part/Sprite artwork snapshots preserve text and styling. Fonts are saved by name and scaling factor, without embedding font files; the receiving system must supply the font for the same appearance. Older drawing snapshots remain readable.

Parameters
textNon-null, null-terminated UTF-8 text of at most 1 MiB; may be empty.
rectFinite local rectangle with right >= left and bottom >= top.
attrsText appearance and transform to copy.
Returns
An owned ElementRef of type type_Text; the caller deletes this handle.
Note
Rendering requires a graphics build. Attach the drawing with Part::setDrawing() to include it in that owner's saved artwork.
Example
std::unique_ptr<pdg::Drawing> drawing(pdg::Drawing::create());
pdg::Attributes attrs;
attrs.textSize(24).textStyle(pdg::textStyle_Bold).fillColor(pdg::Color(1.f, 1.f, 1.f));
std::unique_ptr<pdg::ElementRef> label(drawing->addText("Player 1", pdg::Rect(0, 0, 180, 40), attrs));
label->setText("Player 2");
