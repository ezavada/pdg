glm::mat3 destinationTransform ( const Quad & destination) const

Map drawing bounds into an affine destination.

Requires a finite parallelogram; non-affine quads throw. Degenerate source axes retain unit scale instead of dividing by zero.

Parameters
destinationDestination corners corresponding to the drawing bounds.
Returns
A column-major affine glm::mat3 mapping source geometry into the destination.

Replay drawing contents with parent attributes.

Composes parent and element transforms/opacity without changing stored element attributes. Requires a GUI-capable build.

Parameters
portDestination Port.
parentParent transform and appearance applied to every element.
localStrokesFalse keeps stroke thickness in Port pixels. True scales thickness by sqrt(abs(det(composed transform))).
