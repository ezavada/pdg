◆ addModifier()

AnimationModifierId addModifier ( Modifier callback,
int stage = animationStage_PreConstraint,
int order = 0 )

Register a procedural pose modifier.

Modifiers run after source sampling and persistent overrides. They run by stage, then ascending order, then registration order. Each sees earlier successful edits. Keep evolving controller state in your own objects and apply it to each fresh pose; do not accumulate the previous final pose.

Parameters
callbackSynchronous callable taking AnimationPoseView and const AnimationModifierContext&, returning void. The view expires on return.
stagepdg::animationStage_PreConstraint, pdg::animationStage_Constraint, or pdg::animationStage_PostConstraint.
orderSigned integer sort order within the stage; default 0.
Returns
A nonzero modifier ID.
See also
evaluate()

References pdg::animationStage_PreConstraint.

◆ evaluate()

AnimationPose evaluate ( const AnimationPose & base,
const AnimationTransform & root,
double deltaSeconds,
const std::map< AnimationBoneId, AnimationTransform > & overrides = {} )

Evaluate a fresh pose through the modifier stages.

Copies the base for Clip mode, or creates a reference pose for Reference/Procedural mode, then applies overrides and callbacks. Callback failures roll back only that callback, record a diagnostic, and continue with the remaining entries. Rejects recursive evaluation and invalid inputs.

Parameters
baseFreshly sampled pose supplying the rig and clip source.
rootValid owner root transform in owning-layer coordinates.
deltaSecondsFinite nonnegative elapsed seconds. Zero requests reevaluation without advancing controller time.
overridesAbsolute parent-local transforms indexed by bone ID.
Returns
An owned final pose. The input base is unchanged.
See also
addModifier(), getModifierError()

◆ setSource()

void setSource ( int source)

Select the starting pose for evaluation.

Clip uses the sampled animation; Reference and Procedural start from the rig reference pose. Persistent overrides and modifiers run afterward in every mode. Source selection does not create a separate playback clock. A change requested inside a callback takes effect after evaluation.

Parameters
