Detailed Description

Appearance setters return this image by reference for chaining.

Image A bit image that can be blitted onto the screen You cannot create images directly, they must be loaded by the Graphics Manager

Image * createImageFromOffscreenPort ( Port * port,
bool copyPixels = true )
static

Create a snapshot or a live image of an offscreen surface.

Create an RGBA image from an offscreen port, preserving transparency. Returns null for null or non-offscreen ports. The caller owns one reference. copyPixels=true takes an independent snapshot; false shares the surface and follows drawing. Both images remain valid after closing the source port. The shared surface is retained.

Parameters
portAn open offscreen Port.
copyPixelsDefaults to true for an independent copy. False retains the shared surface and reflects subsequent drawing without copying its pixels for rendering within the same graphics context.
Returns
An Image owning one reference, or nullptr for null or onscreen ports. Call release() when finished. The image has the port's pixel dimensions and transparency.

Both modes survive closure of the source port. A live image keeps its surface alive after the Port is closed; drawing through the closed Port is invalid. Destruction of the underlying graphics context preserves the surface's final pixels for surviving images. Pixel reads and serialization read the current contents; deserialization produces an independent snapshot. Rendering across independent graphics contexts or into the source surface uses a snapshot. setTransparentColor() detaches a live image before changing its pixels.

Note
Available in graphics-enabled builds. The current Port clip does not crop the result. Image opacity is independent of the shared surface.
API stability: 2 — Evolving.
Example
auto& graphics = pdg::GraphicsManager::instance();
auto* surface = graphics.createOffscreenPort(pdg::Rect(128, 128));
if (surface) {
auto* live = pdg::Image::createImageFromOffscreenPort(surface, false);
surface->drawRect(pdg::Rect(16, 16, 112, 112),
pdg::Attributes().fillColor(pdg::Color(1.0f, 0.0f, 0.0f))
.lineStyle(pdg::lineStyle_None));
// live now displays the red rectangle; later surface drawing updates it.
graphics.closeGraphicsPort(surface);
if (live) live->release();
}

Replace this image from an image record; retain the decoded pixels.

Parameters

Loading preserves strip frame layout, opacity, edge clamping and subsection selection; decoded pixels remain available. Malformed records, unavailable resources and changed resource dimensions throw.
