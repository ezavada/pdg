◆ clear()

Port & clear ( const Color & color = Color(0, 0, 0, 0))

Replace pixels inside the current clip with an exact color.

Clear the current clip to an exact RGBA color (transparent by default). Unlike drawing a translucent rectangle this replaces the pixels.

Parameters
colorDefaults to transparent black. Alpha replaces the previous alpha; this differs from drawing a translucent rectangle, which blends with existing pixels.

Works on graphics-enabled onscreen and offscreen ports. The current clip is unchanged. Live images made from an offscreen port reflect the clear on their next draw.

Note
API stability: 2 — Evolving.

◆ setDrawingOrigin()

Port & setDrawingOrigin ( const Point & origin)

Set the Port coordinate at the top left of an offscreen surface.

Set the coordinate at the top left of an offscreen surface and reset its clip. Does not move pixels. Main/window ports reject this operation.

Parameters
originFinite coordinates for the drawing area's top left. Initially (0, 0).

Pixel dimensions and stored pixels do not change. getDrawingArea() reports the new origin and the clip resets to that area. Drawing and clipping now use those coordinates; Image pixel coordinates remain zero-based. This supports rendering a View into a reusable surface without changing its layout coordinates. Onscreen ports and nonfinite origins are rejected with an error.

Note
Requires a Port from GraphicsManager::createOffscreenPort().
API stability: 2 — Evolving.
See also
clear(), getDrawingArea(), Image::createImageFromOffscreenPort()
