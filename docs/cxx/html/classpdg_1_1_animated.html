Detailed Description

template<class T = void, class Base = AnimatedBase>
class pdg::Animated< T, Base >

Programmed transforms, constant rates and scheduled animation.

Base class for programmed movement, rotation, and resizing over time.

Typed animation interface with one shared AnimatedBase state.

Derive an owner from Animated<Owner>. Animated<> is the standalone form. Base selects the shared implementation for extensions such as AnimatedAttributes. Methods return the chosen owner type; further subclasses retain that type.

Animated<T> returns the selected owner type from every chainable operation. Sprite derives from Animated<Sprite>, Part from Animated<Part>, and SpriteLayer from Animated<SpriteLayer>. Animated<> is a standalone object. Use AnimatedBase& or AnimatedBase* for a common interface, including IAnimationHelper callbacks. The shared base owns all state and scheduling; the template adds no second state. Further subclasses retain their selected owner's return type.

Animated separates immediate edits and constant rates from scheduled transitions. All animation durations and waits use floating-point seconds. Setters are immediate and chainable; they cannot consume a wait() or andThen(). Timed change methods require explicit seconds; explicit zero applies immediately outside a sequence. To names specify targets; By names specify additive deltas. grow() and stretch() use factors and change logical size; changeScaleTo()/changeScaleBy() change the independent transform scale. Constant rates continue after a rate transition ends.

Scheduled operations normally run concurrently. andThen() sequences the next operation after the most recently scheduled one; wait() delays the next timed request. Immediate calls after either throw before changing state. cancelSchedule() clears pending sequencing and scheduled work while retaining current constant rates.

Example
sprite.setMovement(40, 0);
sprite.changeMovementTo(0, 0, 0.5); // Ease the rate to a stop in half a second.
sprite.setGrowing(8); // Add eight logical size units per second.
sprite.changeGrowingTo(0, 0.25); // Ease the growth rate to zero.
Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

◆ addAnimationHelper()

template<class T = void, class Base = AnimatedBase>
Self & addAnimationHelper ( IAnimationHelper * helper)
inline

Register a callback after the object's normal animation step.

Helpers run in registration order and receive elapsed floating-point seconds. Returning false retires that registration. Adding an already registered helper is an idempotent operation. A helper may be registered on several owners.

Removing or clearing helpers inside a callback skips their remaining calls on this step. Newly added registrations run on the next step. Removing and re-adding the current helper creates a new registration; returning false only retires the old one.

Parameters
helperNon-null callback object. If ownedByAnimated() returns true, each owner retains a native reference until registration ends and any executing callback returns. The final release deletes the helper. Keep your own addRef()/release() reference if you intend to reuse a helper after retirement. A borrowed helper (ownedByAnimated() returns false) must outlive its registrations and executing callbacks.
Returns
This object, for chaining.
See also
removeAnimationHelper(), clearAnimationHelpers(), IAnimationHelper

◆ andThen()

template<class T = void, class Base = AnimatedBase>
Self & andThen ( )
inline

Start the next timed operation after the most recently scheduled operation finishes.

Uses its remaining duration and delay, not the longest of all concurrent operations. The next request consumes this sequencing state; later calls again run concurrently unless sequenced. A successor acquires its properties and resolves relative targets when it starts. Immediate calls after andThen() throw even if the predecessor has finished. No then() method is provided, so returning an Animated object from an async JavaScript function is safe.

Returns
This object, for chaining.
See also
wait(), cancelSchedule()
