◆ AnimationSpringTarget()

AnimationSpringTarget ( double mass = 1,
double stiffness = 100,
double damping = 20 )

Create a damped spring target.

Starts with zero position and velocity. The helper owns its state independently of Sprites and does not update automatically. All inputs must be finite.

Parameters
massPositive mass; default 1.
stiffnessNonnegative restoring spring coefficient; default 100.
dampingNonnegative damping coefficient; default 20.
Example
pdg::AnimationSpringTarget recoil(1, 100, 20);
recoil.applyImpulse(-2, 0);
auto offset = recoil.update(0, 0, 1.0 / 60);

void applyImpulse ( double x,
double y )

Change spring velocity immediately.

Each velocity component increases by impulse divided by mass. Position remains unchanged. Invalid or overflowing results leave state unchanged.

Parameters

◆ update()

AnimationTargetState update ( double targetX,
double targetY,
double deltaSeconds )

Advance the spring toward a fixed target.

Uses analytic damped-spring integration, treating the target as constant throughout this step. Zero elapsed time preserves state. Invalid or overflowing results leave state unchanged.

Parameters
targetXFinite target x in the same frame as the spring state.
targetYFinite target y in the same frame as the spring state.
deltaSecondsFinite nonnegative elapsed time in seconds.
