Detailed Description

Spring integration, recoil impulses, and world or platform contact locks.

pdg::AnimationSpringTarget updates a position and velocity toward a target and accepts recoil impulses. pdg::AnimationContactTarget locks a contact in world or platform coordinates and releases it over a duration in seconds. Their snapshots are pdg::AnimationTargetState and pdg::AnimationContactState. Use pdg::animationHasTag() to query authored pose tags when deciding contact state.

Test sampled animation metadata for a tag.

Reads sampled metadata without changing playback. Object and tag names are exact and case-sensitive. Missing objects or tags return false.

Parameters
