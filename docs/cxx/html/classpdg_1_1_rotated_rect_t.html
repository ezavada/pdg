Detailed Description

template<typename T>
class pdg::RotatedRectT< T >

Rectangle with rotation for 2D coordinate system. RotatedRect is a class that provides support for dealing with rotating rectangles in 2 dimensional space. RotatedRectT is not used directly in most cases. Use the RotatedRect class, which is the long integer version of RotatedRectT, and has all the same methods. RotatedRectT is a template class that provides support for dealing with rotating rectangles in 2 dimensional space. A floating point version of RotatedRectT is predefined as RotatedRect, but a long integer version of RotatedRectT could easily be declared using the RotatedRectT template.
