Detailed Description

Ordered pose callbacks, animation sources, and two-bone IK.

pdg::AnimationPipeline evaluates callbacks in pdg::AnimationModifierStage order. A callback receives a pdg::AnimationPoseView and pdg::AnimationModifierContext; the view expires when the callback returns. Call pdg::AnimationPoseView::copy() to retain an owned snapshot. Select clip, reference, or procedural input with pdg::AnimationSource.

pdg::AnimationTwoBoneIK describes a two-bone chain and its target. Use pdg::solveAnimationTwoBoneIK() for an owned pose, or register a constraint with pdg::Sprite::addAnimationIK(). pdg::AnimationIKResult reports reach and constraint limits. Zero length fields use rig-declared lengths, or current child offsets when the rig declares none; this follows animated joint offsets without using visual bone widths. Explicit/declared lengths must match the offsets. Nonsingular nonuniform scales and reflections are supported under PDG's component-transform composition. Check pdg::Sprite::getAnimationModifierError() for callback failures.
