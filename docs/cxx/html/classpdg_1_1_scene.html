Detailed Description

Own layers, an isolated physics world, camera advancement and logical timers.

Owns layers, an isolated physics world, a camera and logical timers. pause() freezes simulation and owned timers while drawing remains enabled. removeLayer() transfers responsibility to the caller; disposeLayer() destroys. Scenes draw in construction order, above legacy layers. Use separate scenes for gameplay and an independently animated HUD. release() follows PDG's native reference-count convention; explicitly dispose() to end a scene's lifetime.

Scenes draw in construction order above legacy layers. pause() freezes simulation, physics, owned camera animation and timers while rendering continues. A later HUD scene can share the same Port and continue advancing. Layer camera overrides remain supported; a camera has only one automatic scene owner.

removeLayer() transfers responsibility without destruction. disposeLayer() destroys an attached layer. dispose() cancels timers, disconnects subscribe() registrations, destroys attached layers and releases the world; detached layers survive. Disposal is idempotent and physical cleanup is deferred during traversal. Detach and attach outside traversal and disconnect cross-layer constraints before detachment.

setFixedStep(), advance(), getSimulationTime() and getDroppedTime() use seconds; timer creation and delays use milliseconds. Fixed step zero selects variable-step updates. Host admission is limited to 0.25 seconds and eight fixed steps per update. Discarded time does not advance timers. Fixed-step interpolation affects sprite root transforms during rendering; physics and queries use authoritative state. Camera and skeletal poses hold current state. Timer IDs are positive and local. Repeating intervals must be positive and fire at most once per step. Scene resume preserves individual timer pauses and excludes elapsed paused time. setTimeScale() accepts finite nonnegative values; zero freezes advancement without explicit pause.

subscribe(emitter, handler, type) retains the handler and disconnects the exact registration on disposal; the emitter may be destroyed first. cancel/unsubscribe operations on unknown IDs do nothing. Raw input is controlled independently with setInputEnabled(). Audio and external asynchronous work remain application policy.

Note
Include pdg/sys/scene.h, pdg/sys/spritelayer.h and pdg/sys/sprite.h. Native stack scenes are supported. Heap scenes use addRef()/release() following PDG conventions. Explicitly dispose() before abandoning a scene. Shared ports and artwork retain existing ownership.
pdg::Scene gameplay, hud;
gameplay.setManual(true);
hud.setManual(true);
gameplay.setFixedStep(1.0 / 60);
auto* actors = gameplay.createSpriteLayer();
auto* indicator = hud.createSpriteLayer()->createSprite();
indicator->setSpin(2);
gameplay.pause();
gameplay.advance(0.1); // Held pose.
hud.advance(0.1); // Independent HUD animation.
gameplay.resume();
gameplay.removeLayer(actors);
hud.addLayer(actors); // Explicitly transfer the surviving layer.
hud.disposeLayer(actors);

◆ raycast() [1/2]

std::optional< CollisionQueryHit > raycast ( const Point & start,
const Point & end,
const CollisionQueryOptions & options = {} )

Closest accepted hit, retaining its collider; empty optional if no match.

Return the closest accepted segment hit. Queries inspect current authoritative enabled attached Sprite, Part and Particle colliders, including bodyless colliders, independently of cameras and contact response. Available before stepping and while paused; call outside scene update/draw traversal. Predicates must not mutate geometry, scene membership, results or timing, or recursively query. Predicate failures propagate. Disposed scenes reject queries.

Query current authoritative geometry without advancing simulation. Available while paused and before the first step. Queries during advance, drawing or a query predicate are rejected. Results retain hit colliders. Single-hit calls return an optional retained hit. Multiple-hit calls return scene-owned storage, valid until the next query or scene disposal. CollisionQueryOptions::maxHits caps multiple-hit results (default 16).

Single-hit C++ values and their copies retain their colliders independently. Multiple-hit methods return a const reference to one scene-owned vector, valid until the next query on that scene or disposal. Copy the vector and explicitly retain collider references when keeping multiple-hit data longer. The vector uses reusable storage; geometry snapshots and scratch storage can allocate.

A separate maxHits argument caps cast array overloads; CollisionQueryOptions.maxHits caps overlap results (default 16, range 0 to 1048576). Other options select layerMask intersected with layer queryBits, explicit layers, categoryMask, includeSensors, excludedColliders, excludedBodies and a synchronous boolean predicate. Foreign/detached explicit layers throw. Zero/empty selection matches nothing. Layers default to queryBits 1. queryBits are not serialized.

Hits use scene world coordinates and public shape IDs. Casts sort by travel distance, collider ID then shape ID; overlaps sort by identity and expose only collider/shapeId. Initial touching/overlap counts and returns zero distance/fraction/normal. Nearest points use filled geometry: interior points return themselves at distance zero. No truncation flag is exposed for multiple results. Finite coordinates and nonnegative finite radii/distances are required; boxes must have positive dimensions.

Parameters
startWorld segment start.
endWorld segment end.
optionsOptional scene selection.
Returns
Closest retained hit, or std::nullopt on a miss.
Note
Attach searched layers to a live scene; no physics step is required.
Example
pdg::CollisionQueryOptions options;
options.maxHits = 8;
const auto& hits = scene.raycast(pdg::Point(0, 50), pdg::Point(200, 50), 8, options);
for (const auto& hit : hits) { /* use hit.collider and hit.distance here */ }
// The next query invalidates the multiple-hit records above.
