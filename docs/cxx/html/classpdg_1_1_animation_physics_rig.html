Create physical bodies for an animation pose.

Note
Animation physics requires Chipmunk. The Basic solver supports simple shared-body physics but is intentionally not a backend for animation rigs; expanding it to complex animation physics is not planned. Enable Chipmunk on the SpriteLayer before rig setup.

Validates topology and dimensions before allocating simulation state. Requires Chipmunk support. Keep the space alive until rig destruction and any deferred teardown have completed.

This standalone passive adapter requires all bodies to be Dynamic when using Follow mode. Sprite::setupAnimationPhysics() supplies the controller needed for mixed body modes with Follow.
