std::shared_ptr< const AnimationRig > create ( std::vector< AnimationBone > bones,
std::vector< AnimationSocket > sockets = {},
uint64_t revision = 1,
std::vector< AnimationBinding > bindings = {} )
static

Validate and create an immutable animation rig.

Names must be nonempty and unique within each collection. Parents and binding references must be valid; bone cycles, invalid transforms, negative/nonfinite lengths, and revision zero throw before publication. Input bone order need not be parent-first.

Parameters
bonesBone definitions; vector indices become IDs.
socketsSocket definitions, optionally following point bindings.
revisionNonzero source revision used to identify this schema.
bindingsImage, point, and box definitions; vector indices become IDs.
Returns
A shared immutable rig.
Example
pdg::AnimationBone bone;
bone.name = "root";
auto rig = pdg::AnimationRig::create({bone});
pdg::AnimationPose pose(rig);
