Detailed Description

Optional collision geometry, independent of artwork, animation and body ownership. Sprite, Part and Particle factories own their colliders; retain a returned native reference with addRef/release to keep it after removal. Local shapes follow the owner's affine transform. Bodyless colliders are externally positioned surfaces; sensors only report overlap. Circles and capsules are exact under uniform scale; nonuniform scale/shear approximates curved boundaries with 32 segments per full turn. Solid response requires a dynamic PhysicsBody.

Note
API Stability: 2 — Evolving. This API is implemented and supported, but its contract is still settling. Compatibility is preserved where practical; breaking changes are documented in release notes. See API stability.

Geometry sources and explicit additions
Operation Frame/animation source Caller-added shapes
Sprite.setupFrameCollider / setupAnimationCollider Selects the source and follows subsequent artwork updates Clears previous geometry when selecting the source
addCircle / addCapsule / addBox / addPolygon / addImageMask Continues updating Adds a persistent shape in owner-local coordinates
removeShape Throws for a source-controlled ID Removes that addition only
setCircle / setCapsule / setBox / setPolygon / setImageMask Stops following artwork Replaces all geometry with the supplied shape
clearShapes Stops following artwork Removes all geometry

Source updates preserve IDs by frame or authored box name. Source IDs may be inactive while an animation box is absent, and return when the box reappears. getShapeCount()/getShapeId() enumerate the currently present shapes. getShapeName() returns the authored box name, "frame" for a frame source, or an empty string for an explicit shape. Contacts aggregate convex pieces under each public shape ID.

Uses the entire supplied image, mapped to localBounds. Pixels with alpha at least alphaThreshold become merged convex rectangles; transparent holes and disconnected islands remain empty. Geometry is copied, so subsequent pixel edits require another call. An entirely transparent image has no contact area. Named images can reload discarded CPU pixels; unavailable pixels throw. ◆ setCapsule()

Collider & setCapsule ( const Point & start,
const Point & end,
double radius )

Endpoints are local cap centers; equal endpoints describe a circle.

Replace all geometry with one capsule.

The capsule consists of the line segment between start and end, expanded by radius in every direction. Endpoints are the centers of the rounded ends in owner-local coordinates. Total length is the distance between the endpoints plus twice the radius, and width is twice the radius. Coincident endpoints behave as a circle while retaining collisionShape_Capsule as the public type.

Coordinates are copied. Validation finishes before existing shapes are replaced; the capsule receives a fresh shape ID. This stops any frame/animation geometry source, while preserving collider settings, owner/body association, mass and inertia. NoCollider ignores the operation.

Queries and both solvers use exact capsule geometry under translation, rotation, reflection and uniform scale. Nonuniform scale or shear uses a convex outline with 16 straight segments per semicircle plus the two straight sides; coincident endpoints use the same 32-sided approximation as a deformed circle. All pieces remain one public shape ID. Capsule geometry and IDs survive scene snapshots; older readers without capsule support reject that shape kind.

Parameters
startFinite local center of the first cap.
endFinite local center of the second cap; may equal start.
radiusFinite positive radius in owner-local distance units.
Returns
This Collider, for chaining.
Note
Include pdg/framework.h and use namespace pdg.

◆ setContactHandler()

Collider & setContactHandler ( std::function< void(const ColliderContact &)> handler)

Optional native listener. Callbacks run after solving and may remove owners.

Set the native listener for this collider's contact phases.

The listener runs synchronously after contact solving. Collider pointers in its payload remain valid for the call; retain a handle explicitly to keep it longer. It may remove colliders, bodies, owners or layers. Events already collected for this frame describe the solved frame and can refer to subsequently detached colliders. Exceptions are caught and recorded by getContactError(); a successful dispatch clears that error. Calling the same CollisionWorld::step() recursively from its listener is rejected.

Parameters
handlerFunction receiving one borrowed contact record, or an empty function to remove the listener. This does not change setWantsContactEvents().
Returns
This collider, for chaining.
