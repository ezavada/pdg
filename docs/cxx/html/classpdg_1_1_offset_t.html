Detailed Description

template<typename T>
class pdg::OffsetT< T >

Point for 2D coordinate system. Point is a provides support for dealing with points as x, y floating point values in 2 dimensional space. PointT is not used directly in most cases. Use the Point class, which is the long integer version of PointT, and has all the same methods. PointT is a template class that provides support for dealing with points in 2 dimensional space. A floating point version of PointT is predefined as Point, but a long integer point version of PointT could easily be declared using the PointT template.
