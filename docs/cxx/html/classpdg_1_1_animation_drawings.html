AnimationDrawableId add ( const AnimationDrawableOptions & options,
Callback callback,
const AnimationRig & rig )

Register a drawing callback.

Validates bone, placement, slot, and bounds against the rig before registering. Changes requested between beginFrame() and endFrame() are deferred.

Parameters
optionsDrawing placement and culling settings; see animation_drawable_options.
callbackSynchronous callable returning a shared Drawing or nullptr. Its context expires when it returns.
rigImmutable schema used to validate referenced bones and slots.
Returns
A nonzero registration ID.
See also
remove(), collect()

◆ beginFrame()

void beginFrame ( )

Begin a stable drawing pass.

Snapshots and sorts registrations by order, preserving registration order for ties. Rejects recursive drawing. Pair with endFrame(), including on exceptional exit.

See also
collect(), endFrame()

std::vector< AnimationDrawingSubmission > collect ( int placement,
const std::string & slot,
const AnimationPose & pose,
const AnimationTransform & root )

Evaluate callbacks for a placement within an open frame.

Requires beginFrame(). Exceptions disable only the failing callback and record its error. Null drawings emit no submission. In headless builds, returns an empty vector.

Parameters
placementOne AnimationDrawPlacement value.
slotImage binding name for slot placement; empty for BeforeAll/AfterAll.
poseCurrent evaluated pose belonging to the registered rig.
rootSprite root in owning-layer coordinates.
Returns
Ordered drawing submissions retaining their Drawing and copied world transform.
See also
beginFrame(), endFrame(), error()

◆ remove()

void remove ( AnimationDrawableId id)

Remove a custom drawing registration.

Releases the Drawing or callback and its diagnostic. An unknown valid ID is harmless. Changes requested while drawing are deferred until the current draw finishes.

Parameters
idExisting registration ID returned by add(); remove() also accepts absent IDs.

◆ setEnabled()

void setEnabled ( AnimationDrawableId id,
bool enabled )

Enable or hide a registered drawing.

Does not remove the registration. Throws for an unknown ID. A callback disabled by a failure cannot be reenabled; remove it and register a corrected callback.

Parameters
idExisting registration ID returned by add(); remove() also accepts absent IDs.
enabledTrue to include the drawing; false to skip it.
