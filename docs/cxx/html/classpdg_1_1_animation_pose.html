◆ blend()

AnimationPose blend ( const AnimationPose & from,
const AnimationPose & to,
double influence )
static

Blend two compatible owned poses.

Both inputs must share the same rig instance. Bone and binding transforms interpolate without modifying the inputs; rotation follows the shortest path. Numeric metadata interpolates, integer values truncate, and strings/tags switch at halfway.

Parameters
fromStarting pose.
toDestination pose sharing from's rig.
influenceFinite blend weight from 0 to 1.
Returns
A new blended pose.
