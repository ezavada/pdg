Detailed Description

One public shape hit. Single-hit scene returns and their copies retain collider. Buffer records borrow the buffer's reference until clear/reuse/destruction. point and normal use scene world coordinates. Cast distance is travelled distance; nearest distance is distance to filled geometry. Initial overlaps have fraction/distance zero and a zero normal (no unique entry surface). Their point is the closest filled-geometry point, possibly inside the target. Overlaps expose identity only; their other fields remain zero.
